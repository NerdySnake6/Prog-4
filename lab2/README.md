# Лабораторная работа 2

## Тема

Шаблон проектирования «Декоратор».

## Цель работы

Цель работы - написать простую программу, которая получает курсы валют в
формате JSON, а потом через декораторы преобразует эти данные в YAML и CSV.

## Что сделано

- Использован интерфейс `Component` через `ABC` и `@abstractmethod`.
- `CurrencyJsonComponent` получает данные валют и возвращает JSON.
- `YamlDecorator` преобразует JSON в YAML и умеет сохранять результат в файл.
- `CsvDecorator` преобразует JSON в CSV и умеет сохранять результат в файл.
- Для запросов к ЦБ РФ используется стандартный модуль `urllib`.
- Для CSV используется стандартный модуль `csv`.
- Для YAML используется библиотека `PyYAML`.

## Пример идеи паттерна

Базовый компонент ничего не знает про YAML и CSV. Он просто возвращает JSON.
Декораторы оборачивают компонент и меняют результат:

```python
component = CurrencyJsonComponent(source_data=demo_data)
yaml_component = YamlDecorator(component)
csv_component = CsvDecorator(component)
```

Так можно не переписывать базовый класс, а добавлять новое поведение отдельно.

## Вывод

Паттерн «Декоратор» удобен, когда нужно добавить объекту новое поведение, но не
хочется менять его основной код. В этой работе базовый компонент отвечает за
получение валют, а декораторы отвечают только за формат вывода и сохранение.
